# AI Chatbots LaTeX Fixer for Markdown (Obsidian)

A web-based tool designed to clean up and format LaTeX mathematical expressions generated by AI chatbots (ChatGPT, Claude, Gemini, DeepSeek, etc.) to ensure seamless rendering in Obsidian and markdown processors.

## Features (Planned)
- Fix inline and display LaTeX math formatting issues from AI outputs.
- Convert non-standard AI LaTeX syntax to Obsidian-compatible MathJax/KaTeX syntax.
- Live preview for Markdown rendering with LaTeX math.
- Quick copy and export options.
